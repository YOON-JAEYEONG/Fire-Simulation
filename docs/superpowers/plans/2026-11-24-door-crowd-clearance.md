# 미닫이문 앞 군중 정체 해소 작업 순서

[설계](../specs/2026-11-24-door-crowd-clearance-design.md)

- [x] 깨끗한 mergeing 기준과 밀집·분산 재현 로그를 확보했다.
- [x] 예약 중인 문짝의 이동 범위와 대기 위치를 NPC가 구분하도록 수정한다.
- [x] 비키기·조작 자세 재배치를 캡슐 이동으로 적용하고, 무진전 조작을 해제한다.
- [x] 문 물리 자동화와 원래 층별 배치/화재 조건의 비교 재현을 확인한다.

상태: 최신본 `27961377`의 별도 작업 브랜치에서 에디터 빌드 성공. Main_level, 화재 3, 규칙 기반에서 밀집 배치 Door_14 첫 완전 개방은 화재 후 64.43초 → 40.31초, 75초 종료 시 대피 30/41 → 41/41, 기능 상실 5 → 0. 분산 배치도 20/20 대피했고, 이전에 닫힌 채 정체되던 Door_17이 열렸다. Unreal `YUFS.NPC.Interaction+YUFS.NPC.Navigation` 57개 테스트 통과. 화면 렌더링과 ML 정책 조합은 별도 확인하지 않았다.
