# 문 앞 선두 우선 구현

[설계](../specs/2026-11-24-front-person-door-design.md)

- [x] 기존 플레이의 문 앞 교착 기록과 먼저 갱신된 NPC가 예약하는 경로 확인
- [x] 실제로 이 문을 쓰는 대피자 중 조작 가능한 선두를 선택
- [x] 완전 개방 뒤 조작자의 짧은 우선 통과와 실패 시 해제
- [x] 문/경로 자동 테스트와 원래 밀집 배치에서 순서 확인

상태: `f16ded4`의 기존 맵/화재 데이터를 사용했다. 에디터 빌드 및 문·경로 자동 테스트 57개 통과. 2층 밀집 재현에서 문턱 67cm의 NPC가 먼저 맡고 첫 통과(화재 후 14.85초)까지 같은 NPC였으며 그 NPC의 역방향 통과는 없었다. 41명 중 40명은 관찰 종료 전에 대피하고 0명은 기능을 상실했다. 분산 배치는 방향 고정 직전 빌드에서 20/20 대피했다.
