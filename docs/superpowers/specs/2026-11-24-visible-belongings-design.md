# IT관 소지품의 시각화

최신 IT관 맵의 1·2층 방 안쪽에 배낭과 노트를 실제 레벨 액터로 배치한다. 복도·계단·문 레일은 사용하지 않는다. 기존 맵 지오메트리·조명·연기 설정 및 NPC 행동 확률은 그대로 둔다.

잊은 가방을 찾는 기존 NPC는 출발 지점에 실제 개인 배낭을 갖는다. 같은 가방이 성공한 줍기 뒤에는 NPC 등에 붙고, 취소·위험 증가 시에는 바닥에 남는다. 연습과 재생에서 장식용 소지품이 가짜 줍기 목표가 되지 않는다. 기하·길찾기 결과의 변화를 방지하기 위해 모든 시각용 소지품은 충돌과 NavMesh 영향이 없다.

실제 레벨 저장·재로드 후 양층 배치와 바닥 지지를 확인하고, 개인 가방의 바닥/소지/재생 복원을 자동 테스트로 검사한다.
