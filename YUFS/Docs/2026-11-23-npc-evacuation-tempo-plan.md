# NPC 대피 속도와 판단 지연: 작업 계획

설계: `2026-11-23-npc-evacuation-tempo-design.md`

- [x] JJW 근거 확인과 경보 판단 시간을 조정하고 준비·노출 시간과 분리한다.
- [x] 일반 대피와 탐색 속도를 올리고 기어가기·문 통과와 회복 속도 제한을 유지한다.
- [x] 일반 대피 경로만 연기 거부에서 비용 기반 우회로 변경하고, 대체 경로 탐색에 실패해도 기존 이동을 유지한다.
- [x] 개별 행동·경로 자동 테스트와 실제 화재 3번 재생으로 확인한다.

결과: UE 빌드 성공, `YUFS.NPC` 132개 통과(경고 포함, 실패 없음). 같은 실제 맵에 층별 10명을 배치한 화재 3번 60초 재생에서 2층 탈출 1→10명, 전체 탈출 10→20명, 2층 위험 경로 거부 로그 55→0건, 비용이 낮은 경로로 전환 3건. 각각 한 번의 재생 관찰값이다.
