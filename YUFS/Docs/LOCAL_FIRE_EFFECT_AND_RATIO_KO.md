# 지정 방의 화재 효과와 NPC 확률 소화

## 적용 내용

기존 Prototype 건물과 대피 NPC를 유지한다. 별도의 불 액터나 소화 전용 NPC는 생성하지 않는다.
사용자가 표시한 2층 왼쪽 위 방의 월드 좌표 `(-309.980809, -257.265525, 351.0)`를
기존 `AYUFSHeterogeneousVolume`의 상호작용 목표로 사용한다.
그 볼륨에 불꽃 평면 3개, 연기 평면 2개, 주황색 조명 컴포넌트를 추가했다.
컴포넌트는 충돌과 내비게이션에 영향을 주지 않는다.

## 확률과 행동

`Config/DefaultGame.ini`의 `[YUFS.NpcInteraction]`:

| 설정 | 값 | 의미 |
|---|---:|---|
| TrainedPopulationFraction | 0.65 | NPC별 소화 훈련 집단 배정 확률 |
| SuppressionChoiceProbability | 0.35 | 자격 조건을 만족한 NPC의 화재별 소화 선택 확률 |

두 값은 시연용 설계값이며, 문헌의 실측 비율이 아니다. 전체 20명 중 정확히 7명을
소화 담당자로 배정하는 의미도 아니다. 소화기·화재 발견, 훈련, 위험, 퇴로에 따라
자격 인원이 달라지고, 확률 선택 후에도 소화기 선점이나 경로 실패로 실행을 못 할 수 있다.

1. 기존 대피/인지 흐름 중 실제 시야로 소화기와 화재 위치를 발견한다.
2. 훈련 수준 0.55 이상, 인지 위험 0.65 미만, 도달 가능한 퇴로를 확인한다.
   즉각적 생명 위험, 행동불능, 기어가기, 공식 대피 지시는 소화보다 우선한다.
3. 같은 화재에 대해 NPC당 한 번 확률을 추첨한다. 다른 소화기를 보아도 재추첨하지 않는다.
4. 선택한 기존 NPC가 소화기를 예약하고 이동·획득한다. 동일 소화기 중복 소유를 막는다.
5. 화재 주변 약 2.3m의 도달 가능한 분사 지점을 선택한다. 벽·층·시야를 검사한다.
6. 목표를 향해 회전하고 준비시간 1.5초 후 분사한다. 약제를 초당 0.75 단위 소모하며
   이번에 추가한 국소 효과의 강도를 사용량에 비례해 줄인다.
7. 진압, 약제 소진, 목표 상실, 위험 증가, 퇴로 상실, 시도 제한시간(90초)에 따라
   상호작용을 끝내고 기존 대피 판단으로 복귀한다. 완료 후 같은 프레임의 오래된
   행동 결정을 다시 실행해 소화기를 재획득하지 않도록 차단한다.

## 실행과 변경 파일

루트의 `Launch-NaturalNpcInteractions.ps1`로 실행한다. 이 실행은
`-YUFSBuildingInteractions` 플래그를 사용해 기존 건물에 소화기 4개와 확률 설정을 적용한다.
일반 실행에서 이 플래그를 빼면 해당 시나리오 설정 경로는 실행되지 않는다.
화면의 `FIRE ZONE`으로 발화 방을, `OVERVIEW`로 전체 대피를 확인할 수 있다.

- `Fire/YUFSHeterogeneousVolume.*`: 발화 좌표, 국소 효과, 시작/정지/진압 강도.
- `NPC/Decision/YUFSHumanBehaviorSelectorComponent.*`: 조건부 확률, 화재별 중복 추첨 방지.
- `NPC/Integration/YUFSNpcSuppressionComponent.cpp`: 같은 NPC의 획득·접근·분사·복귀.
- `Simulation/YUFSGameInstance.cpp`: 훈련 집단 설정과 소화기 배치.
- `Content/Python/create_local_fire_materials.py`: 직접 제작한 절차적 머티리얼 생성/갱신.
- `Content/Effects/LocalFire/`: 불꽃·연기 머티리얼 2개. 외부 화재 에셋을 내려받지 않았다.

## 검증 및 한계

2026-09-08 자동 테스트 11개 통과. 확률 테스트에서 자격을 만족하는 1,000명 중
366명이 선택되어 35% 정책의 허용 범위를 통과했다. 이는 사람의 실측 통계가 아니다.
실제 Prototype 재생에서 기존 NPC C_4의 획득 → 분사 → LocalFireSuppressed 복귀를
확인했다. 다른 NPC는 소화를 거절하고 기존 행동을 계속했다.
화면 캡처와 실행 로그는 루트 `Logs/`에 있으며, 마지막 수정 이후의 검증 기록을 우선한다.

최종 재빌드 후 `Logs/LocalFireFinalRun2.log`에서 C_4의 시작(12:52:50 UTC),
획득(12:52:51), 분사(12:52:58), 완료 복귀(12:53:05)를 확인했다.
C_6는 뒤늦게 소화를 선택했지만 C_4가 진압하자 자신의 접근을 중단했다.
이번 실행에서는 C_15와 C_16이 소화를 선택하지 않았다. 완료 직후 재시작 로그는 없다.
`Logs/LocalFireFinal_14.png`와 `LocalFireFinal_26.png`에서 효과의 전후 상태를 확인했다.
최종 테스트 기록은 `Logs/LocalFireFinalTests.log`이며 11개 모두 Success다.

원본 `fire.uasset` 및 `smoke_data.bin`이 없어 CFD/VDB 연기·온도장을 복구한 것은 아니다.
이번 진압은 추가한 국소 시각 효과에만 영향을 주며 원본 녹화형 VDB를 변경하지 않는다.
따라서 물리적 화재 진압 모델이나 안전 검증 결과로 사용하면 안 된다.
효과 강도는 라이브 재생용이며 과거 타임라인으로 이동할 때 진압 이력이 복원되지 않는다.
소화 자세는 기존 애니메이션을 활용한 임시 매핑이며 전용 노즐 조준·손 IK는 후속 작업이다.
기존 건물 유리의 Nanite 경고와 누락된 원본 연기 파일 오류는 이 기능과 별도로 남아 있다.
