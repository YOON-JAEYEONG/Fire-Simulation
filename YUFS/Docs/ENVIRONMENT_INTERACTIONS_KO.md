# NPC 환경 상호작용 구현

## 이번에 추가한 범위

기존 대피 NPC에 `EnvironmentInteraction` 컴포넌트를 붙였다. 기존 소화기 발견·예약·획득·분사는
`NpcSuppression`이 계속 담당한다. 새 컴포넌트는 문 사용과 다른 사람에게 대피 안내하기를 담당한다.
새 NPC나 불을 생성하지 않으며, 기존 건물 맵에 문을 임의 배치하지 않는다.

### 문 열기

- `AYUFSInteractionDoor`를 실제 출입구에 배치한다. 원점은 경첩 위치, 기본 패널은 폭 100cm·높이 220cm다.
- 문이 내비게이션의 다음 경유점 방향 140cm 안에서 충돌 검사에 잡힐 때만 사용 후보가 된다.
- 근처의 아무 방 문이나 찾아 열지 않는다. 잠금(`bLocked`), 고열(`bHot`), 사용 거리, 다른 사용자의 예약을 검사한다.
- 한 명만 조작할 수 있으며, 기본 1.2초 동안 90도 회전한다. 완전히 열린 뒤 통행 충돌을 해제한다.
- 잠금/고열/거리 이탈/20초 초과/명령 변경 시 중단한다. 취소 시 예약을 반환하며 2초 후 다시 판단할 수 있다.
- 자동 닫기·방화문 폐쇄·문에 끼임 방지·손잡이 IK는 이번 범위가 아니다. 기본 문은 단순 패널 프로토타입이다.
- 닫힌 문도 경로가 문 앞까지 이어지도록 NavMesh에는 영향을 주지 않게 했다. **잠긴 문을 우회하는 경로의 차단 간선 처리는 경로 담당이 추가해야 한다.**
- `bHot`은 외부 화재 데이터/상호작용 담당이 갱신하는 입력이다. 누락된 온도 데이터를 만들어 내지 않는다.

### 다른 NPC 돕기

- 대상 NPC의 `EnvironmentInteraction.RequestAssistance(true)`를 호출하거나, 현재 Freeze 상태인 사람을 발견하면 후보가 된다.
- 같은 층·800cm 이내·벽에 가리지 않은 사람만 대상으로 한다. `bAcceptsAssistance=false`는 거절이다.
- 기존 행동 선택기의 도움 후보에 실제 발견한 대상만 넣는다. 도움 선택 확률은 기존 성향 기반 가중치를 유지한다.
  전체 NPC 중 고정 비율로 도움 담당을 배정하지 않는다. 대피 결심을 강제로 해제하는 별도 도움 확률은 추가하지 않았다.
- 도움 행동을 선택하면 대상 한 명을 예약하고, 완전한 경로가 있는지 검사한 뒤 기존 이동기로 접근한다.
- 140cm 이내에서 2초간 안내한다. 대상에게 도달 가능한 안전 출구가 있는지 현재 시뮬레이션 프레임으로 검사하고 대피 판단을 재개시킨다.
- 대상 상실·도움 거절·위험 증가·공식 대피 지시·행동 변경·시간 초과 시 취소하고 예약을 해제한다.
- **현재 도움은 당황한 보행 가능자에게 대피를 안내하는 기능이다. 부상자를 회복시키거나 업기·끌기·동행 운반하는 기능이 아니다.**
  행동불능/기어가기 상태인 사람에게 성공한 구조로 보고하지 않는다.

## 팀원 병합 경계

| 담당 | 전달/사용할 데이터 |
|---|---|
| 상호작용 | 발견한 문/사람 ID, 위치, 예약·실행·완료·실패 피드백 |
| 경로 | `AssistTarget`의 대상 ID·위치, 기존 Navigator 이동, 잠긴 문의 경로 차단 처리 |
| 모션 | `Assist`·`OperateDoor` 의미 지시를 받아 전용 애니메이션/IK 구현 |
| 판단 | 실제 발견된 도움 대상만 후보로 선택, 기존 소화 확률 유지 |

`bUseExternalNavigationDriver`, `bUseExternalMotionDriver`는 기존 역할 전환을 유지한다.
새 컴포넌트의 `bUseExternalExecutor=true`는 해당 컴포넌트의 발견·실행을 모두 외부 담당에게 넘긴다.
이는 소화 컴포넌트를 끄는 설정은 아니다. 외부 인계 시 발견 스냅샷도 외부 담당이 새 revision으로 갱신해야 한다.
피드백은 시작 시 저장한 요청 revision으로 반환하여 오래된 요청 결과가 새 요청에 적용되지 않게 한다.

## 관련 파일

- `Source/YUFS/Fire/YUFSInteractionDoor.*`: 조작 가능한 문과 소유권.
- `Source/YUFS/NPC/Integration/YUFSNpcEnvironmentInteraction.*`: 발견·예약·문 사용·도움 실행.
- `Source/YUFS/NPC/Integration/YUFSTeamIntegrationTypes.h`: 도움 대상 정보 추가.
- `Source/YUFS/NPC/Integration/YUFSTeamIntegrationComponent.cpp`: 도움 대상의 경로/상호작용 전달, 문 모션 의미.
- `Source/YUFS/NPC/YUFSEvacuationNPC.*`: 기존 NPC의 실행 흐름과 이동기 연결.
- `Source/YUFS/Tests/YUFSDecisionModelTests.cpp`: 문 수명주기·도움 예약·팀 계약 회귀 테스트.

## 검증 범위

C++ 빌드를 통과했다. 2026-09-09 자동 테스트 13개 모두 통과했으며,
최종 결과는 `Logs/EnvironmentInteractionTests2.log`에 있다. 최초 테스트의 임시 월드
중복 초기화 오류를 수정하고 전체 테스트를 다시 실행했다.
실제 건물 출입구에 문을 배치한 플레이 검증, 도움 접근/안내의 장면 검증은 아직 별도로 필요하다.
타임라인 되감기에 문 회전·도움 예약 상태를 기록/복원하는 기능은 이번에 추가하지 않았다.
