# 대피 중 두고 온 가방 회수

사용자가 요청한 소수 행동으로, NPC 일부가 원래 자리를 떠나 출구로 이동한 뒤 뒤늦게 가방을 떠올린다. 기본 후보율은 20%인 시뮬레이션 값이며, 시드로 한 번 정한다. 이미 준비 중 소지품을 챙겼거나, 위험하거나, 짧고 같은 층의 경로가 없는 사람은 후보라도 회수하지 않는다.

돌아가는 대상은 자신의 초기 자리다. 정상 출구 행동의 짧은 하위 동작으로 처리하고, 성공하면 잠깐 가방을 챙기는 기존 제스처 후 대피한다. 위험 상승, 공식 대피 안내, 통행 불가, 제한시간은 즉시 회수를 취소한다. 연기만으로 포기하지 않는 기존 **대피**와, 연기가 짙으면 포기하는 **선택적 가방 회수**를 분리한다. 탈출 이후 건물 재진입, 가방 메시 에셋, 새 화재 오브젝트는 추가하지 않는다.

수락 기준: 돌아가기와 챙기기를 구분해 확인할 수 있고, 성공·취소 후 다시 출구로 이동한다. 같은 에피소드에서 같은 NPC가 반복해서 돌아가지 않는다. 위험 노출, 안전한 문 통과, 일반 대피와 팀 인터페이스의 보호조건은 유지한다.
