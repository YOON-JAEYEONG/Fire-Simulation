# 대피 중 가방 회수 구현

설계: `2026-11-23-belongings-return-design.md`

- [x] 출발 거리와 시드 후보, 준비 단계, 재시도 제한을 기존 NPC에 연결한다.
- [x] 안전한 같은 층 경로만 사용하고, 회수 제스처와 대피 복귀를 움직임·상호작용에 연결한다.
- [x] 자동 테스트와 실제 맵 재생에서 성공 및 위험 취소를 확인한다.
