## 달라진 판단

- NPC의 출구 후보를 건물 전체 목록에서 개인이 기억한 출구로 제한했다. 익숙한 출구 행동도 임의의 최근접 출구를 만들어 내지 않는다. 수정 전 검사에서 이 잘못된 익숙한 출구 선택을 재현했다. 경보 후 최근접 조회 검사는 기존 미로딩 데이터 안전 장치 때문에 수정 전에도 통과했으므로 두 검사가 모두 실패했다고 해석하지 않는다.
- 기본 NPC는 기존 Main의 `bIsFamiliarEntry` 표식이 있는 입구 하나를 기억한다. 여러 표식이 있으면 스폰 지점에서 가까운 표식을 선택한다. 이것은 작성된 사전 지식이며 NPC가 실제로 그 문을 통과해 들어왔음을 추적한 기록은 아니다. 방문객은 `RememberMarkedEntry=false`, 특정 진입문은 `FamiliarEntryExitID`, 별도 사전 지식은 `InitiallyKnownExitIDs`로 설정한다.
- 출구를 실제 눈높이·거리·수평 시야각·벽·연기 시야 감쇠 조건 안에서 보면 기억한다. 화재 전에는 실제로 존재하지 않는 미래 BIN 연기를 시야에 적용하지 않는다. 화재 중 데이터가 미로딩이면 새로운 출구를 보았다고 확정하지 않는다.
- 한번 배운 출구는 시선을 돌리거나 연기가 가려도 기억한다. 현재 위치를 항상 원격 조회하여 갱신하지 않으며 다시 보거나 안내를 받아야 갱신한다. 제거된 출구 액터는 목표에서 제외한다. **출구를 안다는 것과 그 경로가 안전하다는 것은 별개**이며 기존 개인 위험 기억, 경로 점수, 위험 경로 대기/재검사 절차를 유지한다.
- 출구를 모르거나 알고 있는 출구를 임시로 제외하면 근처의 실제 NavMesh 경로 후보를 찾고 걸으며 둘러본다. 개인별 방문 지점과 탐색 난수를 사용한다. 기본 반경450cm, 후보8방향, 생성 간격 최소2초, 한 구간15초, 탐색 이동 상한160cm/s다. 전역 출구 위치를 이용해 탐색 방향을 고르지 않는다. 이미 위험 경로 재검사 대기 중이면 탐색으로 대기를 우회하지 않는다.
- 주변 대피자를 따라갈 때는 그 사람의 실제 가까운 위치를 목표로 한다. 다른 NPC 내부의 최종 출구 좌표를 훔쳐 읽지 않는다. 정지한 사람과 다른 추종자는 대피 흐름의 선두로 취급하지 않아 순환 추종을 줄였다.
- 가까운 NPC가 명시적으로 출구를 알려주거나, 범위 안의 직원 안내가 구체적인 등록 출구를 알려줄 때 기억한다. 일반 경보/방송만으로 모든 출구를 배우지 않는다. 새 `ReceiveExitGuidance(Sender)`는 같은 월드·거리·층 높이·가림·행동 불능 등을 확인한다. 기존 도움/주변 알림 행동과 연결했으며 상대가 출구를 모르면 유효한 정보를 만들어 주지 않는다.
- 내부 이동과 팀 전달 정보에서 목적지 존재 여부를 별도 bool로 전달한다. 세계 원점의 실제 출구도 유효하며, 목표가 없을 때 `(0,0,0)`으로 달려가지 않는다. 탐색 목표는 `InvestigateTarget/SearchingForExit`로 전달하여 아직 모르는 지점을 안전 출구로 표시하지 않는다.
- 개인 탐색 시계는 NPC의 활성 시간으로만 진행한다. 기존 일시정지와 타임라인 리뷰 중에는 탐색 시간·목표를 진행시키지 않는다. 탐색 중 기본 모션은 걷기/둘러보기이며 실제 낮은 자세는 계속 기어가기 정책을 따른다.
