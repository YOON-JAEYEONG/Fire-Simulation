1. 서로 마주 오는 두 줄: 왼쪽6명 x=650~1150, 오른쪽6명 x=1850~2350, 모두 y=-900의 실제 NavMesh 위에 비중첩으로 배치했다. 수정 전에도45초에12명이 모두 반대쪽 목표 영역에 도달했다. 이 조건에서 대향 교착을 재현했다고 주장하지 않으며 같은 방향의 앞사람 우선 규칙은 유지한다. 대향 통행의 반복 실행에서는 결과 차이도 확인하여 아래 추가 보완과 한계를 함께 기록했다.
2. 통로에 정지한 사람: 오른쪽으로 이동할6명 앞 x=1500,y=-900에 같은 팔레트 NPC를 두었다. 이 사람만 외부 내비게이션 소유/이동 컴포넌트 정지로 고정하되 신체 충돌은 유지했다. 특정 상호작용을 실제로 수행한 실험은 아니며 **정지한 신체 장애물의 분리 실험**이다. 수정 전25초에 뒤의6명 모두 그 사람을 지나지 못했고, 앞쪽 NPC가 후퇴를 반복했다.25초에 이동 소유권과 원래 이동 컴포넌트를 되돌리자 정지한 사람도 정상 AI로 걸어가기 시작했고45초에는7명 모두 목표에 도달했다. 사람을 순간 이동·삭제하거나 충돌을 끄지 않았다.

## 원인과 최소 수정

기존 로컬 복구는 YieldingTo가 NPC이기만 하면 항상 첫 번째 유효한 후퇴 공간을 선택했다. 그래서 전역 경로가 없는 정지한 사람이나 상호작용으로 멈춘 사람에게도, 움직이는 군중에게 길을 비워 주는 것과 같은 후퇴 정책을 반복했다.9단계의 고정 물체 우회 선호는 이러한 사람에게 적용되지 않았다.

이제 같은 방향으로 이동하거나 잠시 양보 중인 앞사람에게는 기존 공간 비우기를 유지한다. 정지·상호작용 상대나 반대 방향의 상대에게는 기존 양보 시간을 거친 뒤 상대의 진행선에서 벗어나는 지지된 공간을 우선 고른다. 짧은180cm 검사로는 실제 예측 정지 거리 너머의 사람을 놓칠 수 있어, 상대까지 거리와 두 사람 신체 여유만큼 검사하되700cm로 제한했다. 후보 자체의 안전과 선택 이후의 경로 검사는 계속 별개다. 후보 뒤쪽의 먼 벽 때문에 유효한 피할 공간까지 버리지 않도록 상대 신체/진행선과의 분리도 선호도에 반영한다. 옆으로만 이동했다가 같은 중심선으로 즉시 복귀하는 반복을 줄이려고 안전 검사를 통과한 앞 대각 후보도 추가했다(최대21개). 상대와 충돌하지 않는 후보끼리는 실제로 그 사람을 돌아서 전진하는 공간을 우선한다. 모든 후보는 기존 NavMesh 투영, 전체 신체 캡슐, 연속 바닥/계단, 개인 위험 검사에 먼저 통과해야 한다. 전진 공간 검사에도 상대 신체 충돌을 포함한다.

실제 Main에서는 상대가 약300cm 앞에 있을 때부터 멈춰, 문 너머의 피할 공간에 진입조차 못 하는 원인도 확인했다. 정지/상호작용 상대에게는 중심 간 거리가 두 캡슐 반지름 합+45cm보다 클 때 입력을 기본의0.15~0.6배로 줄여 접근한다. 그 안에서는 계속 멈추고 양보하며 기존 물리 충돌/RVO를 유지한다. 실제 벽·문을 우회하지 않고, 전진 공간까지 들어간 뒤 지지된 대각 공간으로 복구할 수 있게 하는 변경이다. 잠시 양보 중인 같은 방향의 군중에게는 이 정지 상대 접근 규칙을 적용하지 않는다.

이는 옆 공간이 없을 때 억지로 사람이나 벽을 통과시키는 변경이 아니다. 전진 구간은 후보의 선호도이며 위험이 안전하다는 인증도 아니다. 이동 중에는 기존 위험 재검사와 충돌이 계속 적용된다. 별도 전역 통행 제어나 순간 이동, 충돌 해제, 강제 대피 성공은 추가하지 않았다.

통행 우선순위·순환 대기 대표·기본 좌우 규칙은 기존 방식으로 유지했다. 개인 ID 정렬로 바꾸는 중간 실험은 같은 방향의 줄에서 우선권이 섞이며 실제 통행이 나빠져 채택하지 않았다. 따라서 객체 생성 상황과 프레임/RVO에 따른 실행 차이를 모두 제거한 변경이라고 해석하면 안 된다. 이 한계는 추후 통로 단위 방향 예약/공정성 모델의 검증 범위로 남긴다.
