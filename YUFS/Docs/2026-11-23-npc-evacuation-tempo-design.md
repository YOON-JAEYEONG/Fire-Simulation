# NPC 대피 속도와 판단 지연

일반 대피 보행과 안전한 탐색 구간의 목표 속도를 25% 올리고, 이미 감지한 화재 단서를 확인하는 판단 시간을 35% 줄인다. 계단·문 충돌, 교통 양보, 기어가기, 소지품 준비, 화재 인지·고열 임계값은 그대로 둔다.

설계 범위: 기존 JJW 상태머신에 두 가지 설정값을 둔다. 경보 신뢰도와 성향 분포를 유지해 단서 없는 NPC나 회의적인 NPC 모두가 한꺼번에 움직이지 않게 한다. 근거 확인 시간만 줄이며, 판단이 빨라져도 물리적 병목이나 위험한 경로를 강제로 통과시키지 않는다. 수치 조정은 사용자가 요청한 기존 기능의 튜닝 범위에서 정했다.

경로 후속 요청: 대피 중 연기는 경로 비용으로만 적용한다. 완전하고 더 낮은 비용의 우회로가 있으면 바꾸고, 없으면 원래 경로가 연기만으로 중단되지 않게 한다. 고열, 누락된 FDS 데이터, 물리적 장애물과 진화·구조 접근의 안전 확인은 기존 규칙을 유지한다.

완료 기준: 기본값과 기존값(배율 1)을 고정 시드로 비교해 판단과 이동 속도가 빨라지고 준비·기어가기가 유지되는지 확인한다. 짙은 연기만 있는 유일한 경로는 수용, 옅은 경로가 있을 때는 우회, 고열·끊긴 경로는 거부하는지 검증한다. 실제 Main_level 화재 3번 재생에서 탈출 집계와 남은 정체를 확인한다.
